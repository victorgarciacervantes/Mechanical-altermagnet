# Spin-Momentum Locking in Mechanical Altermagnets

Welcome to the official repository for my Master's thesis project conducted at the **University of Amsterdam Metamaterials Laboratory** (UvA & VU Amsterdam) under the supervision of **Dr. Corentin Coulais** and **Prof. Jasper van Wezel**.

This project bridges quantum condensed matter theory and classical active metamaterials by developing a theoretical and computational framework to model spin-momentum locking in mechanical altermagnets composed of non-reciprocal actuators.

---

## Key Project Files

To navigate this repository efficiently, start with these core deliverables:

*  **`master_thesis_article.pdf`**: The complete Master's thesis document detailing the theoretical foundations, numerical modeling, and experimental results.
*  **`master_thesis_slides.pdf`**: The defense presentation slides summarizing the background, methodology, and key findings.
*  **`analysis_hamiltonians.ipynb`**: The primary Jupyter Notebook containing the core computational pipeline, numerical simulations, Hamiltonian matrix analysis, and data visualizations (`Kwant`, `Qsymm`, `SciPy`).
